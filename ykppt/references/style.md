# 视觉规范（style.md）

> 从 4 份真实组会/答辩 PPT（20260415 / 20260716 / 20260731 / 多主体跨域协同）反推，
> 并把其中互相矛盾的写法**收敛成唯一自洽的一套**。所有数值均为实测，
> 单位 1/100 inch（英寸×100），画布 1333×750。
>
> 生成器 `scripts/ykrender.py` 的常量与本文一一对应；改本文必须同步改代码，
> 反之亦然。`scripts/verify_deck.py` 会按本文的阈值做静态检查。

---

## 1. 画布与网格

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 1333 × 750 | 16:9，即 13.33in × 7.5in |
| 安全边距 | 左右 35 | 任何形状不得越界 |
| 页眉带 | y 0 → 103 | 五边形+校徽+章标签+斜切横幅，由母版提供 |
| 正文区上界 | y 103 | 页眉下那条横线 |
| 正文区下界 | y 642 | 再往下是结论条 / 参考文献 / 页码 |
| 页脚带 | y 642 → 750 | 结论条 642–686，参考文献 646–731，页码 710–750 |

**结论**：正文可排版区域为 `x 35..1298 / y 103..642`，共 1263 × 539。
需要结论条的页，正文区下界收紧到 **y 615**。

## 2. 色板

### 2.1 主色（唯一来源：母版主题 `theme1.xml`）

| 语义 | 值 | 用在哪 |
|---|---|---|
| `NAVY` 深蓝 | `#142C76` | 章标签文字、小标题、结论条左侧色条 |
| `DEEP` 主蓝 | `#0E1E52` | 主题 dk2，渐变终点 |
| `BRAND` 品牌蓝 | `#014DA1` | 主题 accent1，横幅渐变起点、结论条描边、图标 |
| `SKY` 浅蓝 | `#5BB0E6` | 主题 accent2，次要分隔线 |
| `PALE` 浅底 | `#EAF3FA` | 卡片底、结论条底、表格斑马行 |
| `PALE2` 更浅底 | `#DDEEFA` | 卡片描边 |
| `WHITE` | `#FFFFFF` | 页底、横幅文字 |

> 横幅 / 五边形 / 页眉条的渐变都是 `accent1 → tx2(lumMod 90%, lumOff 10%)`，
> 角度 10800000（=180°）。这个渐变**在 slideLayout 里**，不要用代码重画，
> 直接克隆样板页即可继承。

### 2.2 强调色（语义固定，不可混用）

| 语义 | 值 | 用在哪 |
|---|---|---|
| `RED` 正文强调 | `#C00000` | 正文里要突出的短语、被否定的结论 |
| `RED2` 高亮红 | `#FF0000` | 结论句、图注、⚠ 风险项；目录当前章 |
| `TIP_YELLOW` 标注字 | `#FFFF00` | **仅**红底气泡里的术语名 |
| `RED_BANNER` 红底 | `#FF0000` | 定义/术语注释气泡底 |
| `DASH_GRAY` 虚线框 | `#7F7F7F` | 待强调的框（square dot） |
| `DASH_AMBER` 警戒框 | `#FFC000` | 一句总结框（square dot） |
| `NODE_RED` | `#F6645F` | 流程图节点 1/3 |
| `NODE_TEAL` | `#3CB6B9` | 流程图节点 2 |
| `NODE_BLUE` | `#123987` | 流程图节点 3 强调 |
| `TEXT_SUB` | `#4E4E4E` | 次要文字、图表轴标签 |

**红线**：正文强调只用 `RED` 与 `RED2` 两级；`TIP_YELLOW` 离开红底气泡就是错的
（白底黄字不可读）。这条在原 4 份文件里被违反过，规范里明确禁止。

## 3. 字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文正文/标题 | `微软雅黑` | 唯一中文字体 |
| 西文/数字 | `Arial` | 与中文混排时同 run 内显式设 latin |
| 封面主标题 | `Arial` + 粗体 | 48pt，实测就是 Arial |

**废弃**：`黑体`、`思源黑体 CN Medium`、`+mn-ea`、`+mj-ea`。
原文件混用这 4 种，效果近似但字重/字宽不一，导致同一份 PPT 里行距肉眼可见地不齐。
统一到微软雅黑后行高一致、跨机器不缺字体。

中文字体**必须同时设** `font.name` 与 East-Asian 字形
（python-pptx 里要手写 `<a:ea typeface="微软雅黑"/>`，见 pitfalls）。

## 4. 字号阶梯

只有这 8 级，不允许出现阶梯外的字号：

| 级别 | pt | 用在哪 |
|---|---|---|
| `TITLE` | 28 | 页眉右侧横幅标题、页眉左侧章标签 |
| `LEAD` | 20 | 定性句 / 小标题 / 表格表头 / 目录条目 |
| `BODY` | 16 | 正文默认（结论条、要点、卡片正文） |
| `DENSE` | 14 | 密集正文、卡片内说明、图注 |
| `SMALL` | 12 | 参考文献、表格正文、图中标签 |
| `TINY` | 10 | 页脚注释、极小标签（尽量不用） |
| `COVER` | 48 | 封面主标题 |
| `TOC_HEAD` | 54 | 目录页「目录」二字 |

## 5. 行距与对齐

| 项 | 值 |
|---|---|
| 正文行距 | 1.5 倍（实测原文件正文全部是 1.5） |
| 标题行距 | 1.0–1.3 倍 |
| 正文对齐 | 两端对齐（`JUSTIFY`）；单行短句用左对齐 |
| 结论条对齐 | 居中 |
| 表格单元格 | 垂直居中，四边 margin 0.1in |
| 段落间距 | 不设 space_before / space_after，靠行距 |

**1.5 倍行距 + 16pt 是这套模板的呼吸感来源**，不要为了塞内容压到 1.0。
塞不下就减字，不要压行距。

## 6. 页眉（母版提供，禁止重画）

| 元素 | 几何 | 说明 |
|---|---|---|
| 五边形 | (36, 0) 80×99 | 渐变深蓝，承载校徽 |
| 校徽 | (47, 17) 57×57 | 图片 |
| 章标签 | x 118, y 26 | 28pt 粗 `NAVY`，文本如「一、研究背景」 |
| 斜切横幅 | (456, 18) 830×64 | 渐变蓝，白色 28pt 粗居中标题 |
| 页眉横线 | (60, 103) 1203×0 | 细分隔线 |

**标题字数上限 26 字**（28pt 下 830pt 宽约容 28 字，留余量）。
超过 26 字必须缩写；横幅不做自动缩字号（缩了就和别的页不齐了）。

## 7. 页脚

| 元素 | 几何 | 规格 |
|---|---|---|
| 结论条底 | (35, 642) 1264×44 | 圆角，底 `PALE`，描边 `BRAND` 1.09pt |
| 结论条色条 | (35, 642) 7×44 | 实心 `NAVY` |
| 结论条文字 | (51, 638) 1248×46 | 16pt 粗，居中 |
| 参考文献 | (7, 646) 1278×91 | 12pt，行距 1.0 |
| 页码 | (1199, 710) 69×40 | 来自母版占位符，`-N-` 格式 |

**结论条铁律**：一页只允许一句话，不超过 **52 个汉字**（16pt 粗居中一行约 55 字）。
它是这套模板最强的叙事装置——每页用一句话告诉听众「所以呢」。

## 8. 三种页面的垂直布局

### 8.1 有结论条（推荐，正文区 y 103 → 615）
```
103  ┃ 定性句 20pt 粗（y 111，高 77）
180  ┃ 分隔线 y 180.3
190  ┃ 内容区（卡片 / 流程 / 表格），到 y 600 为止
600  ┃ ← 留白 ≥ 15
615  ┃ （结论条在 642）
```

### 8.2 无结论条（正文区 y 103 → 642）
```
103  ┃ 定性句
190  ┃ 内容区，到 y 630
630  ┃ 参考文献 12pt（若需要）y 646 起
```

### 8.3 纯图页
图占满 `x 35..1298 / y 103..642`，等比缩放进这个框并居中。
**整页图塞进窄条会糊**（原 pitfalls 已记录），能占满就占满。
